@AGENTS.md

See also [README.md](./README.md) for the Claude Code plugin in `docs/abca-plugin/`. The plugin provides interactive guided workflows for setup, deployment, repository onboarding, task submission, and troubleshooting through the `/setup`, `/deploy`, `/onboard-repo`, `/submit-task`, `/status`, and `/troubleshoot` skills. To activate the plugin, run Claude Code with `claude --plugin-dir docs/abca-plugin`.
