---
title: "Prerequisites"
---

You need the following:

- A deployed CDK stack (see the [Developer guide](/sample-autonomous-cloud-coding-agents/developer-guide/introduction))
- A Cognito user account (see [Authentication](/sample-autonomous-cloud-coding-agents/using/authentication))
- **Repositories must be onboarded** before tasks can target them (see [Repository onboarding](/sample-autonomous-cloud-coding-agents/customizing/repository-onboarding))
- For the CLI, Node.js installed, and the CLI built with `cd cli && mise run build`
