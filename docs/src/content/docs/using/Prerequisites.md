---
title: "Prerequisites"
---

- The CDK stack deployed (see [Developer guide](/sample-autonomous-cloud-coding-agents/developer-guide/introduction))
- A Cognito user account (see [Authentication](/sample-autonomous-cloud-coding-agents/using/authentication) below)
- **Repositories must be onboarded** before tasks can target them (see [Repository onboarding](/sample-autonomous-cloud-coding-agents/customizing/repository-onboarding) below)
- For the **CLI**: Node.js installed; build the CLI with `cd cli && mise run build`
